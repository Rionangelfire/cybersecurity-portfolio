DEX Workspace — cybersecurity operator workspace

During Hack The Box labs, time was lost deciding what to do next — not on the boxes, but on the order of operations. Notes were scattered, and there was still no clear “what now?” after a scan.

A single-file workspace that lives in the browser. Add a host, paste nmap output, and it recommends the next action — SMB first, then web, then SSH — with the commands to copy. Hosts are the center: services, credentials, findings, loot, and notes all hang off the machine you're on. When you're done, one click builds your assessment notes. A Gemini-powered copilot (with your own API key) gets the full context with every question, so answers fit the box you're on.

HTML JavaScript (vanilla) localStorage Gemini API Markdown documentation
Public release v1.0.0 (MIT license) — complete documentation with screenshots. Public source repository, pinned on GitHub profile.

Worm Dex — incident-response & lab reference

When a worm hits the network, the five response steps need to be at hand — searching for them mid-incident wastes critical time. Lab commands were scattered across notes too.

A Pokédex-style cheat sheet (Game Boy green) with the five incident-response steps — disconnect, kill the process, grab the logs, block re-entry, rotate the keys — each with the real Linux and PowerShell commands, plus seven HTB entries: recon, web enum, SMB, reverse shells, stabilizing a shell, privesc checks, file transfer. Tap a command, it copies. A rotating daily security tip from a bank of 32, and a built-in AI chat for questions mid-box.

IOC Monitoring Project — part of Echp

A Python monitor (ioc_monitor.py) that watches log data over UDP syslog on port 514, extracts IP addresses, domains, and MD5 hashes, matches them against indicators of compromise, and writes scored JSON alerts. It turns raw log lines into structured alerts, so a pattern is visible instead of buried in text.

Built as a practice ground — the indicators it ships with are placeholders, and the email-alert step is not wired up. The JSON logging and SIEM alert output are the working parts.

Codex of Echoes — tamper-evident narrative archive

A structured archive of a mythic AI conversation — the Diamond Prince, Nova Echo, and the Codex — stored in SQLite and JSON with a 3D viewer, and a hardened second build whose hash chain makes tampering evident.
